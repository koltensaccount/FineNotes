# FineNotes fork release notice

FineNotes was originally written by Joost. This release includes code from
[FineNotes 2.8.3](https://github.com/Joost-8/FineNotes/tree/18daa971432785a6952e4a871cb2ebd2cd00b064)
and modifications by the fork contributors recorded in Git history.

On 2026-11-07 the fork incorporated and adapted upstream equation editing,
PDF and text utilities, and shape selection in commits `398f9e8` and
`11fbbd8`. The 2026-11-08 fork changes include inline handwriting save
protection, icon artwork, and menu and settings revisions.

See [third-party notices](THIRD_PARTY_NOTICES.txt) for bundled libraries.

The [1.5.1-beta.93 source tag](https://github.com/koltensaccount/FineNotes/tree/1.5.1-beta.93)
contains the corresponding source, assets, lockfile, and build scripts.
With Node.js 22.12 or later, run `npm ci` and `npm run build`.
