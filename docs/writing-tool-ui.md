# Writing tool UI

Independent `feature/writing-tool-ui`, based on current upstream FineNotes 1.5.0. This branch changes UI only: ink sampling, pressure settings, nib multipliers, serialization, and notebook model are unchanged. Tool-specific customizable defaults and width migration are developed on the existing presets branch, then combined on `integration/kolten`.

Ball uses a straight uniform stroke; Fountain a fine curved/tapered sample; Brush a wider expressive wave/ribbon; Highlighter a broad translucent marker. The main Pen control and the options control reflect the current type. The chooser reuses FineNotes' popover with four finger-sized preview/name/hint rows, accessible names and pressed state. Pressure-enabled samples illustrate the type chooser; the live thickness preview respects the current pressure setting.

One SVG preview helper supplies chooser, active identity, quick widths and thickness editor. It consumes nominal stored width, current color/type, optional Pen line style, opacity and paper. The editor reports actual nib millimeters (including the existing Brush 1.8× and Highlighter 4× scale); stored widths and ink are unchanged. Compact samples magnify widths for legibility and bound extremes; the large preview approximates physical scale. Dashed/Dotted are optional preview inputs so the independent UI branch need not depend on the line-style feature.

The thickness editor contains a live paper-backed sample, mm readout, finger-sized slider and visual preset rows. The generic component also accepts optional Save/Replace/Remove/Restore callbacks for the customizable-preset integration. Slider input updates the active width, quick-width samples and live preview immediately. Preset rows and preview redraw in place; input/focus is not replaced on each movement. Writing popovers are bounded to the pane and choose above-anchor space when needed. Preset lists scroll independently at short heights; controls wrap at narrow widths instead of shrinking targets.

Highlighter preview/swatches use its existing 0.4 alpha and multiply treatment on the notebook paper. Planned default colors are yellow `#f2d45c`, green `#8bcb84`, cyan `#78c3df`, pink `#e99cb5`, peach `#f2af7e`; nominal widths 5/8/12 page px mean about 4.1/6.6/9.8 mm after the existing nib multiplier. Dark-paper highlights remain subtle under the existing blend; previews do not brighten or change the stored ink to hide that limitation. Fresh/restored defaults and backward-compatible per-tool width migration belong to `feature/customizable-writing-presets`, not this independent UI branch.

Tests cover distinctive sample geometry/state, pressure settings, colors, alpha/multiply on white/cream/yellow/dark papers, nib/mm scale, optional dashed/dotted round-cap previews, live slider/preset refresh, repeated refresh without duplicate controls, and bounded desktop/portrait/landscape/Split View popovers. Real browser rendering is inspected on the final integrated components before release; physical iPad verification remains pending.
